# Lernwiese
Grundschul-Lernapp (Deutsch & Mathe, Klasse 1–2) fürs iPad.

App: https://mettigel1993-hue.github.io/Buchstabenwiese/

Aufs iPad: Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Danach die App **nur über das Symbol** starten
(dort bleibt der Fortschritt gespeichert) und einmal online öffnen, dann läuft sie auch offline.
